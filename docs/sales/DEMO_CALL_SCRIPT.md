# Demo call script

## Agenda

1. Understand the firm's current workflow
2. Show Aria on dummy matters
3. Show strongest current support areas
4. Show honest limitations
5. Discuss controlled beta fit

## Discovery questions

- Which matter types take the most admin time today?
- Where do client follow-ups break down?
- How do you currently gather confirmations and missing documents?
- What parts of draft preparation are most repetitive?

## Close

If the workflow fit looks strong, propose a 30-day controlled beta with dummy or sandbox matters first and real client data only after legal, privacy, and security review.
