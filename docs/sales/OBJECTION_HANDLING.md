# Objection handling

## "We already have a practice system"

Aria is not trying to replace every system on day one. The strongest current value is the workflow between evidence, client confirmations, draft preparation, and review visibility.

## "AI is risky"

That concern is fair. Aria keeps review markers visible, blocks low-confidence extraction from automatic mapping, and keeps outputs ready for agent final review.

## "We do many subclasses"

Aria shows support levels honestly. Core workflows are stronger today, and the long tail remains visible with checklist-first or scaffold labels instead of fake automation claims.

## "We cannot risk client data"

The beta should start with dummy or sandbox matters. Real client data should only be considered after legal, privacy, and security review.
