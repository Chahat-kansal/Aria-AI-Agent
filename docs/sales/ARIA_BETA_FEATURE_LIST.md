# Aria beta feature list

## Strongest current beta capabilities

- Secure staff workspace and separate client portal flow
- Matter and client tracking
- Evidence upload and review workflow
- Source-linked field extraction for supported documents
- Client confirmation workflow
- AI-assisted draft preparation with review gates
- Full draft output for core supported subclasses
- Pathway analysis for agent review
- Visa knowledge search with source-linked guidance for agent review
- Operations dashboard with deadlines, reminders, and value metrics
- Editable invoice document workflow
- Launch controls and platform admin redaction
