# Aria agent demo script

Use only dummy or sandbox data.

## Opening

Aria is an AI-assisted Australian migration case-preparation platform. It helps firms organise evidence, collect client confirmations, generate review-ready draft outputs, and keep every workflow ready for agent final review.

Aria does not auto-lodge, does not replace migration-agent judgement, and does not provide final legal advice.

## Demo flow

1. Open the owner dashboard and show the matter queue, readiness scores, and review warnings.
2. Open a Subclass 500 or 482 matter and show:
   - missing evidence
   - extracted fields
   - source snippets
   - validation issues
   - client confirmation requirements
3. Open the full application draft and show:
   - applicant summary
   - required document panel
   - safety summary
   - missing markers
4. Open the client portal and show:
   - separate client login
   - upload status
   - messages
   - confirmations
   - appointment request
5. Open operations and show:
   - deadline command centre
   - client response tracker
   - matter health score
   - estimated hours saved
6. Open subclass support and explain honest support levels:
   - full field autofill
   - full staff draft
   - checklist and intake
   - checklist only
   - scaffold only
7. Open launch readiness and provider integrations:
   - what is configured
   - what is still blocked
   - why safety gates stay visible
8. Open invoice builder and show the editable invoice document flow.

## Closing

Position Aria as a controlled beta for firms that want better structure, clearer client chasing, and faster draft preparation, while keeping final responsibility with the registered migration agent.
